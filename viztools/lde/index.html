    What to take away

      Reading the table

      • The OS column runs in kernel mode, with full privilege.
      • The hardware column happens by itself, with no software involved.
      • The program column runs in user mode, on the real CPU, at full speed.
      • The highlighted line is the one running now.

      Registers are saved twice on a switch: the hardware pushes them onto the kernel stack on every trap, and the OS copies them into the process structure when it decides to switch.
