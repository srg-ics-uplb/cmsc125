TLBs: faster translations

A page table lookup means an extra memory reference for every address, so hardware caches recent virtual‑to‑physical translations in a small, fully-associative cache called the translation-lookaside buffer. Follows the Paging: Faster Translations (TLBs) chapter of OSTEP (Chapter 19).
