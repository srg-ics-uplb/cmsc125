# Course Introduction **Welcome to CMSC 125!** The aim of this course is to introduce students to operating systems concepts. # Course Objectives

🎯 Learning Goals

At the end of the course, you should be able to: * describe the purpose and functions of an operating system; * design and implement programs to perform simple operating system tasks; and * evaluate the performance of different operating system algorithms.
# Course Prerequisite This course will require that you have taken **CMSC 123, Data Structures**. # Course Materials and Schedule * You will be provided with **video lectures** and a PDF version of the set of **presentation slides** used in the videos as well as a set of **labs** for you to do, mostly coding.
