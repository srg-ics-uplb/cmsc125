CS 3013

Operating Systems

3 Credit Hours

Course Description

This course provides a comprehensive introduction to operating systems principles and design. Students will learn about process management, memory management, file systems, and system security. The course emphasizes both theoretical concepts and practical implementation through programming assignments and system analysis.

Prerequisites: CS 2011 (Data Structures), CS 2012 (Computer Organization), and MATH 2001 (Discrete Mathematics)

Course Objectives

Upon completion of this course, students will be able to:

  • Understand the fundamental concepts and principles of operating systems design and implementation
  • Analyze and evaluate different process scheduling algorithms and their performance characteristics
  • Design and implement memory management strategies including virtual memory systems
  • Understand file system organization, implementation, and security mechanisms
  • Analyze deadlock prevention, avoidance, and detection algorithms
  • Implement system calls and understand kernel-level programming concepts
  • Evaluate operating system performance and optimization techniques
  • Understand security threats and protection mechanisms in modern operating systems

Course Topics

The following topics are covered based on ACM Computing Curricula recommendations:

  • Overview of Operating Systems: History, types, and basic concepts
  • System Structures: System calls, system programs, and operating system design
  • Process Management: Process concept, process scheduling, and inter-process communication
  • Threads: Multithreading models, thread libraries, and threading issues
  • Process Synchronization: Critical section problem, semaphores, and monitors
  • CPU Scheduling: Scheduling algorithms, algorithm evaluation, and multiprocessor scheduling
  • Deadlocks: System model, deadlock prevention, avoidance, and detection
  • Memory Management: Memory allocation, paging, segmentation, and virtual memory
  • Virtual Memory: Demand paging, page replacement algorithms, and memory-mapped files
  • File Systems: File concept, directory structure, file system implementation, and recovery
  • I/O Systems: I/O hardware, application interface, and kernel I/O subsystem
  • Mass Storage: Disk scheduling, RAID structure, and storage management
  • Protection and Security: Access control, authentication, and security threats
  • Distributed Systems: Network structures, distributed coordination, and distributed file systems
  • System Performance: Performance measurement, system tuning, and optimization techniques
